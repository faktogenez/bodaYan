# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.1.0] - 2026-11-25

### Added

- Новый логотип с монограммой BDY (Боря, Даша, Ян) — семейная концепция бренда.
- Концепция бренда «Бодаян»: название собрано из первых слогов имён детей.
- **Системный трей** — иконка BDY, тултип с версией, меню «Открыть/Выход», сворачивание в трей при закрытии окна.
- **Строка «О программе»** — название и версия лаунчера в футере главного экрана.
- Логотип v2: белые вставные панели на гранях куба, объёмные 3D-буквы, пиксельная текстура травы/земли.

### Changed

- **Ребрендинг:** лаунчер переименован из `AppleLauncher` в `bodaYan Launcher`.
- Обновлено название во всех частях кодовой базы: `package.json`, `index.html`, `main.js`, `config.json`, `updater.js`, `launcher-version.json`, `README.md`.
- `appId` изменён на `com.bodayan.launcher`, `productName` — `bodaYan Launcher`.
- Каталог данных изменён на `%LOCALAPPDATA%\bodaYan`.
- Версия поднята до 1.1.0.
- `selfUpdate.currentVersion` в `config.json` синхронизирован с `package.json` (1.1.0).

### Security

- Аудит безопасности: валидация никнейма, безопасное формирование путей, улучшенная обработка ошибок.
- Усилен CSP, добавлена валидация ввода пользователя.

### Performance

- Удалён неиспользуемый код, оптимизированы модули обновления и запуска.

## [1.0.1] - 2026-11-19

### Added

- Иконка приложения (`assets/icon.ico`, размеры 16–256 px) — подключена к сборке EXE и окну лаунчера.

### Changed

- Версия поднята до 1.0.1 (проверка механизма самообновления).

## [1.0.0] - 2026-11-19

Первый публичный релиз.

### Added

- Portable-сборка одним EXE (`electron-builder`, x64, asar, максимальное сжатие).
- Интерфейс в стиле Apple (glassmorphism) с настраиваемой темой через `config/config.json`.
- Динамическая смена фонового изображения при каждом запуске.
- Запуск Minecraft 1.16.5 + Forge с флагами `--add-opens` (совместимость с Java 17).
- Оффлайн-авторизация (UUID v3 через MD5) — режим «локальный игрок».
- Исправление библиотеки `authlib` (2.1.28 → 2.3.31) для работы сетевой игры.
- Прогресс-бар со стадиями: библиотеки, ассеты, Forge, загрузка файлов.
- Автоподключение к серверу (`quickPlay`) и автоскрытие окна при запуске игры.
- Управление списком серверов: `servers.dat` перезаписывается из конфига (с резервной копией).
- Автообновление игровых файлов по манифесту (SHA1 + размер, докачка через `.part`).
- Самообновление лаунчера через GitHub Releases (подмена EXE внешним `.bat`).
- Модуль поиска Java: `javaPath` → встроенная JRE → `java` из PATH.
