# AppleLauncher

Кастомный лаунчер Minecraft 1.16.5 (Forge) в стиле Apple (glassmorphism), на Electron.
Распространяется одним portable-EXE — без установки и зависимостей.

## Возможности

- Запуск Minecraft 1.16.5 + Forge в один клик.
- Оффлайн-режим (локальная авторизация по нику).
- Автовыбор списка серверов (`servers.dat` формируется из конфига).
- Скачивание/обновление игровых файлов по манифесту (SHA1 + размер, докачка).
- Самообновление лаунчера через GitHub Releases.
- Смена фонового изображения при каждом запуске.

## Требования

- Windows 10/11 x64.
- Java 17 (либо встроенная JRE рядом с EXE в папке `jre/`).

## Быстрый старт

1. Скачай `AppleLauncher-<версия>.exe` со страницы [Releases](../../releases/latest).
2. Положи файл в отдельную папку и запусти.
3. Нажми **Играть**. При первом запуске рядом с EXE появятся `config/` и `minecraft/`.

## Настройка

Основной файл — `config/config.json` (создаётся при первом запуске из встроенного шаблона).

| Секция | Параметр | Описание |
|---|---|---|
| `launcher` | `defaultUsername` | Ник по умолчанию |
| `launcher` | `server.host` / `server.port` | Адрес сервера |
| `launcher` | `memory.min` / `memory.max` | ОЗУ (МБ): по умолчанию 2048 / 4096 |
| `launcher` | `javaPath` | Путь к Java (пусто = автопоиск: `jre/` рядом с EXE → `java` из PATH) |
| `servers` | `enforce` / `list` | Принудительный список серверов в сетевой игре |
| `selfUpdate` | `enabled` / `manifestUrl` | Автообновление лаунчера |
| `updater` | `enabled` / `manifestUrl` | Обновление игровых файлов по манифесту |
| `theme` | цвета, радиус, blur | Оформление интерфейса |

## Автообновление

Манифест последней версии: `releases/latest/download/launcher-version.json`.
Если версия в манифесте новее установленной — EXE скачивается и подменяется автоматически
(Windows), после чего лаунчер перезапускается.

## Сервер (для администратора)

В `server.properties` сервера: `online-mode=false` — иначе оффлайн-клиенты не подключатся.
